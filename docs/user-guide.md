# iMemo 사용자 및 운영 가이드

본 문서는 웹 브라우저(클라우드 PC)의 HTML 에디터에서 작성한 서식 문서를 가로형 비표준 매트릭스 코드로 화면에 표시하고, macOS(SwiftUI) 리더기에서 화면 캡처 영역을 지정하여 원본 서식 그대로 복원하는 **iMemo 시스템**의 사용 가이드입니다.

## 2. 클라우드 PC: 웹 에디터 사용법 (`web/index.html`)

1. **파일 열기**:
   - `web/index.html` 파일을 크롬, 엣지, 사파리 등 임의의 웹 브라우저에서 엽니다.
   - 외부 인터넷 연결이나 별도 설치 없이 100% 오프라인으로 작동합니다.
2. **문서 작성**:
   - 상단 툴바를 사용하여 제목(H1~H3), 굵게(B), 기울임(I), 밑줄(U), 취소선, 글머리 기호 목록, 표 등을 자유롭게 작성합니다.
3. **옵션 설정**:
   - **가로 해상도 폭**: `현재 모니터 가로폭 맞춤`, `1920px`, `1600px`, `1200px(기본)`, `1000px`, `800px`, `직접 입력` 중 선택.
   - **코드 색상 옵션**:
     - `2컬러 (흑백)`: 기본값. 원격 데스크톱 압축 노이즈에 가장 강함.
     - `4컬러 (2비트/셀)`: 데이터 용량 2배.
     - `8컬러 (3비트/셀)`: 데이터 용량 3배.
     - `16컬러 (4비트/셀)`: 최대 용량 4배.
   - **셀 픽셀 크기**: `8px (기본/권장)`, `6px`, `10px`, `12px`.
   - **슬라이드 간격**: `400ms`, `600ms`, `700ms (기본/권장)`, `1000ms`, `1500ms`.
4. **이미지 생성**:
   - 하단 파란색 **[이미지 생성 (IMC 코드)]** 버튼을 클릭합니다.
   - 파일 저장이 아닌, 에디터 바로 아래에 가로로 긴 직사각형 바코드가 표시됩니다.
   - 데이터가 1장에 들어가지 않는 대용량인 경우 자동으로 N장의 슬라이드로 순환 재생되며, 프레임 번호(`프레임 1/3`)와 진행 바가 함께 표시됩니다.
   - **[⛶ 전체화면 확대]** 버튼을 누르면 캡처하기 쉽도록 화면 가득 확대 표시됩니다 (ESC로 닫기).

## 3. macOS: iMemo 리더기 사용법 (`ImemoReader.app`)

### 3.1 실행 방법
- 터미널에서 실행:
  ```bash
  open /Users/conan/py_dev/imemo/ImemoReader/ImemoReader.app
  ```
- 또는 파인더(Finder)에서 `ImemoReader/ImemoReader.app`을 더블 클릭하여 실행합니다.

### 3.2 최초 권한 설정 (화면 기록)
- macOS의 보안 정책에 따라 화면 영역을 캡처하려면 **화면 기록(Screen Recording)** 권한이 필요합니다.
- 앱 실행 후 [영역 선택] 또는 [캡처 시작]을 누르면 시스템 설정 창이 뜨며, `iMemo 리더기`의 화면 기록 권한을 토글해 주시면 됩니다.

### 3.3 화면 영역 캡처 & 자동 복원
1. 맥 화면에 원격 클라우드 PC 창(원격 데스크톱 등)을 띄우고, 위 웹페이지의 바코드를 화면에 표시합니다.
2. iMemo 리더기 상단 툴바에서 **[영역 선택]** 버튼을 클릭합니다.
3. 화면이 반투명하게 어두워지면, 원격 창의 바코드 주변을 마우스로 드래그하여 사각형으로 지정합니다.
   *(테두리 주변 여백이 약간 포함되어도 앱이 자동으로 검정색 바코드 외곽 테두리를 정확하게 찾아냅니다)*
4. 선택한 영역은 자동으로 저장되어 다음 실행 시에도 유지됩니다.
5. 상단 **[캡처 시작]** 버튼을 클릭합니다.
6. 리더기가 250ms 간격으로 원격 화면을 고속 캡처하며 프레임을 수집합니다:
   - 상단에 `[1][2][3]` 상태 칩이 표시되며 수집 현황을 실시간으로 확인 가능합니다.
   - 원격 데스크톱 화면 전송 중 일부 프레임이 건너뛰어지더라도(Frame Drop), 내장된 **XOR 패리티 복구 프레임**을 통해 즉시 손실 복원됩니다.
7. 모든 프레임이 수집되면 **신호음과 함께 즉시 원본 HTML 서식 그대로 복원**되어 화면에 나타납니다.

### 3.4 복원 문서 활용
- **서식 미리보기**: 복원된 HTML을 웹뷰 형태로 깔끔하게 렌더링하여 확인합니다.
- **HTML 소스**: 소스 코드 보기로 전환하여 태그를 직접 확인할 수 있습니다.
- **[HTML 복사]**: 클립보드에 HTML 원본을 복사합니다.
- **[텍스트 복사]**: 서식 태그를 제외한 순수 텍스트만 복사합니다.
- **[저장...]**: `.html` 파일로 내보냅니다.
- **[이미지 파일 열기...]** / **드래그앤드롭**: 보조 기능으로, 캡처된 스크린샷 이미지 파일을 창 안으로 끌어다 놓아도 바로 디코딩됩니다.

## 4. 비표준 및 보안 설계 특징

- **비표준 매트릭스 레이아웃**: 일반 QR 코드와 달리 가로로 긴 직사각형 형태이며, 4개 모서리의 파인더 패턴이 비대칭 구조로 설계되어 상용 QR 스캐너로는 스캔되지 않습니다.
- **키스트림 난독화(Scrambling)**: 헤더, 페이로드, 오류정정 바이트 전체가 전용 시드(`0x494D434D`)의 PRNG 키스트림과 XOR되어 비표준 노이즈로 렌더링됩니다.
- **실시간 팔레트 캘리브레이션**: 바코드 상단/하단에 기준 색상 셀이 배치되어 있어 원격 데스크톱 비디오 압축(YUV420 등)으로 인한 색상 왜곡이 발생해도 유클리드 거리로 정확한 색상 인덱스를 판정합니다.
- **GF(256) 멀티블록 인터리브 오류정정**: 약 30%의 Reed-Solomon 오류정정 패리티가 셀 전체에 교차 배치되어 화면 스케일링, 블러, 노이즈를 극복합니다.
- **CRC32 무결성 검증**: 데이터가 단 1비트라도 오염된 경우 복원을 엄격히 거부합니다.
