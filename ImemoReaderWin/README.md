# iMemo Reader for Windows (Rust 네이티브)

**iMemo Reader Win**은 클라우드 PC(원격 데스크톱 등) 환경의 웹 에디터(`web/index.html`)에서 생성된 **가로형 비표준 매트릭스 코드(IMC)**를 Windows 화면에서 고속 연속 캡처하여 원본 서식 문서(HTML 및 첨부 WebP/JPEG 이미지) 그대로 복원하는 초경량, 고성능 Windows 네이티브 애플리케이션입니다.

---

## 📌 주요 특징

### 1. Windows 네이티브 초고속 화면 캡처 & 자동 정렬
- **Win32 GDI & BitBlt 가속**: 관리자 권한이나 무거운 백그라운드 서비스 없이 1~2ms 수준의 초저지연 화면 캡처.
- **Per-Monitor V2 DPI 인식**: 고해상도(QHD, 4K) 및 디스플레이 배율(125%, 150%, 200%) 환경에서도 1:1 물리적 픽셀을 왜곡 없이 정확하게 캡처.
- **반투명 마우스 드래그 영역 지정기 (`RegionSelector`)**:
  - `[✂️ 영역 선택]` 클릭 시 전체화면 반투명 오버레이가 실행되며 마우스 드래그로 바코드 영역 지정.
  - 초록색 점선 박스 및 실시간 HUD 배지 (`📍 X, Y, W, H px`) 표시 (ESC: 즉시 취소).
  - 지정한 영역 좌표는 로컬 설정(`%APPDATA%\iMemo\config.json`)에 자동 저장되어 다음 실행 시 영구 유지.
  - 상단 툴바에서 좌표 직접 수동 미세 조정 지원.

### 2. 비표준 보안 & 노이즈 자동 복원 (macOS Swift와 100% 호환)
- **비표준 키스트림 난독화**: 전용 시드(`0x494D434D`) 32비트 XorShift PRNG 키스트림 XOR.
- **실시간 팔레트 캘리브레이션**: 상·하단 기준 바를 샘플링하여 비디오 압축(YUV420 등) 색상 왜곡 자동 보정 (2, 4, 8, 16컬러 지원).
- **GF(256) 멀티블록 인터리브 Reed-Solomon 오류정정**: 약 30% 패리티로 화질 손상 및 압축 노이즈 완벽 복원.
- **슬라이드 프레임 드롭(누락) 25% XOR 패리티 자동 복구**: 여러 프레임으로 분할 전송 중 프레임 드롭 발생 시 누락 프레임 즉시 자동 재구성.
- **IEEE 802.3 CRC32 무결성 검증**: 단 1비트 오염 시에도 복원 거부.
- **RFC 1951 Raw DEFLATE / Zlib 디코딩**: 원본 서식 및 첨부 WebP/JPEG 이미지 완벽 복원.

### 3. 복원 문서 뷰어 & 다양한 활용
- **서식 미리보기 모드**: 본문 텍스트와 내장 첨부 이미지를 인라인 렌더링.
- **HTML 소스 보기 모드**: 원본 HTML 소스 코드 확인 및 직접 복사.
- **🌐 [브라우저에서 열기]**: 시스템 기본 브라우저(Edge, Chrome 등)에서 표, 제목, 첨부 이미지 등 완전한 웹 서식으로 즉시 열람.
- **📋 [HTML 복사]** / **📝 [텍스트 복사]** / **💾 [HTML 저장...]** 지원.
- **다양한 입력 지원**:
  - 화면 연속 캡처 (`F5`)
  - 클립보드 이미지 붙여넣기 (`Ctrl + V`)
  - 이미지 파일 열기 (`Ctrl + O`, PNG, JPG, WebP, BMP 지원)

## 🚀 빠른 시작

### 1. 실행 파일 실행
```bash
# 디버그 실행
cargo run

# 릴리스 실행
cargo run --release
```

### 2. 사용 흐름
1. 클라우드 PC의 Chrome에서 `web/index.html`을 열고 문서를 작성한 뒤 **[이미지 생성 (IMC 코드)]**를 누릅니다.
2. Windows에서 `ImemoReaderWin`을 실행하고 상단 **[✂️ 영역 선택]**을 클릭하여 원격 창의 바코드 영역을 드래그합니다 (좌표 자동 저장).
3. **[▶ 캡처 시작]** (또는 단축키 **`F5`**)를 누르면 자동으로 프레임을 수집하여 원본 서식 문서로 복원합니다.
4. 복원된 문서는 **[HTML 복사]**, **[텍스트 복사]**, **[브라우저에서 열기]**, **[HTML 저장...]**으로 활용합니다.
